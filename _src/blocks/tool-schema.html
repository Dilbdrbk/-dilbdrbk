Free tool

Entity schema generator

Describe the entity behind a website and copy the JSON-LD for its entity home. The example shows the Person markup of this site.

JSON-LD
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Person",
  "@id": "https://dilbdrbk.com.np/#person",
  "name": "Dil Bahadur B.K.",
  "url": "https://dilbdrbk.com.np/",
  "jobTitle": "Semantic SEO Specialist",
  "image": "https://dilbdrbk.com.np/assets/img/dil-bahadur-bk.jpg",
  "description": "Semantic SEO specialist in Kathmandu, Nepal.",
  "sameAs": [
    "https://www.linkedin.com/in/dil-bahadur-b-k-3927642ab/",
    "https://github.com/Dilbdrbk"
  ]
}
</script>

Paste the code into the head of the entity home, such as the homepage or the About page, then test the page in the Rich Results Test.

03 Approach

How I approach semantic SEO

Four habits guide every project.

All ten habits

  1. Start with the entity

    I define the central entity and its attributes first, so the whole site speaks about one subject with authority.

  2. Map the topic before writing

    I outline the topical map and content architecture first. Briefs then pair entity-based optimization with search intent.

  3. Learn from the source

    Search engine patents, research papers and official statements reveal which signals matter. I check official statements against real data.

  4. Test, then trust

    A/B tests separate SEO facts from myths. I validate each idea on test pages before it reaches a live project.
